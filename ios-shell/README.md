# iOS shell (placeholder)

A real Xcode project (`.xcodeproj` / `.xcworkspace`) needs to be created from Xcode on a Mac —
it can't be generated from this Windows environment.

## What to do when you're ready to start Phase 9

1. Open Xcode → File → New → Project → App (SwiftUI, Swift).
2. Bundle identifier: `com.vocabia.app` (matches Android `applicationId` for consistency).
3. Deployment target: iOS 15+ recommended.
4. Drop the generated project into this `ios-shell/` folder.
5. Reuse the JSON content from `/content-pipeline` and the algorithm spec from `/docs/algorithm.md` —
   both are platform-agnostic.

Until then, this folder is just a placeholder so the repo structure matches the roadmap.
